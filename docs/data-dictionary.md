# Data dictionary

Every column of every Excel Table in the workbook. Column names are the authoritative field names: R1 field names are used exactly as R1 defines them, never renamed. The display label is the field name in sentence case.

| Term | Meaning |
|---|---|
| Edit mode | `editable` cells hold record values; `formula` cells are calculated and must not be typed over; `read-only mirror` cells copy pinned R1 configuration |
| Ownership | `R1 field` is defined by an R1 schema; `R3` is a workbook-only column |
| Validation source | The named list (Lookups tab) that the cell's drop-down uses; every list comes from a pinned R1 file or an R3 schema |
| Export | The export file that carries the column (see `config/export-map.yaml`); helper columns are never exported |
